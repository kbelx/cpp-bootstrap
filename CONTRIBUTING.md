## English

Thank you for your interest in **C++ Bootstrap** (`cpp-bootstrap`)!

### Pull Requests and Code Contributions
This is a personal and portfolio project maintained exclusively by the author. For this reason, **this repository is not accepting external contributors or Pull Requests** — any Pull Request submitted will be closed without merging.

However, this project is licensed under the **MIT License** ([`LICENSE`](LICENSE)): you are completely free to **fork** the repository, use it, and modify your own copy however you like.

### Issues (Bugs, Feedback & Suggestions)
**Issues are very welcome!** Feel free to open an Issue if you:
- Found a bug or unexpected behavior;
- Have feedback on the generated templates or CLI behavior;
- Want to suggest a new feature or improvement.

When reporting a bug, including the details below helps a lot:
1. Operating system and version (Windows, Linux, or macOS);
2. Compiler and CMake version (e.g., MSYS2 GCC, Clang, MSVC);
3. Command executed and steps to reproduce;
4. Expected vs. actual output.

### Pull Requests e Contribuições de Código
Este é um projeto pessoal e de portfólio mantido exclusivamente pelo autor. Por esse motivo, **este repositório não está aceitando contribuidores externos nem Pull Requests** — qualquer Pull Request aberto será fechado sem merge.

### Issues (Bugs, Feedback e Sugestões)
**Issues são muito bem-vindas!** Fique à vontade para abrir uma Issue caso você:
- Encontre algum bug ou comportamento inesperado;
- Queira deixar feedback sobre os templates gerados ou sobre a CLI;
- Tenha sugestões de melhorias ou novos recursos.

Ao relatar um bug, incluir os detalhes abaixo ajuda bastante:
1. Sistema operacional e versão (Windows, Linux ou macOS);
2. Compilador e versão do CMake (ex.: MSYS2 GCC, Clang, MSVC);
3. Comando executado e passos para reproduzir;
4. Resultado esperado vs. resultado obtido.
